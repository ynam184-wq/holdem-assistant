# Holdem Compass

텍사스 홀덤의 프리플랍부터 플랍·턴·리버까지 균형 전략(GTO)을 근사하고, 각 액션의 빈도와 칩 기대값(EV)을 BB 단위로 비교하는 브라우저 앱입니다.

## 실행

`index.html`을 더블클릭해도 작동합니다. 로컬 서버로 실행하려면 이 폴더에서 다음 명령을 사용하세요.

```powershell
& "C:\Users\young\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" -m http.server 8080
```

이후 브라우저에서 `http://localhost:8080`을 엽니다.

## 모바일에서 사용

### 같은 Wi-Fi에서 확인

`start-mobile.cmd`를 더블클릭하면 PC 주소와 모바일 접속 주소가 표시됩니다. 휴대폰과 PC를 같은 Wi-Fi에 연결하고 표시된 `http://...:8080` 주소를 휴대폰 브라우저에서 여세요.

이 방식은 모바일 화면 테스트용입니다. PC가 켜져 있고 서버 창이 실행 중이어야 하며, 일반 HTTP 로컬 주소에서는 휴대폰의 서비스 워커와 완전한 앱 설치 기능이 제한될 수 있습니다.

### 홈 화면에 앱으로 설치

폴더 전체를 GitHub Pages, Netlify, Vercel 같은 HTTPS 정적 호스팅에 배포합니다. 배포 주소를 휴대폰에서 연 뒤 상단의 `앱 설치` 버튼을 누르세요.

- Android/Chrome: 설치 프롬프트 또는 메뉴의 `앱 설치`
- iPhone/Safari: 공유 버튼 → `홈 화면에 추가`
- 설치 후에는 독립 실행 화면과 오프라인 앱 셸을 사용할 수 있습니다.

PWA 구성 파일은 `manifest.webmanifest`, `service-worker.js`, `icons/app-icon.svg`입니다.

## 계산 기준

- 선택한 홀카드와 커뮤니티 카드로 7장 족보를 직접 평가합니다.
- 7장 중 가장 강한 5장을 골라 최종 족보를 판정합니다.
- 총 2인부터 8인까지 지원하며 인원수에 따라 1,600~3,200회 시뮬레이션합니다.
- 인원·포지션·유효 스택·상대 액션에 따라 균형 핸드 범위를 추정하여 승률 계산에 반영합니다.
- 무승부는 팟 분할 비율로 승률에 반영합니다.
- 플랍과 턴에서는 현재 족보를 개선하는 아웃츠와 리버까지의 개선 확률을 계산합니다.
- 유효 스택을 푸시/폴드, 숏, 미들, 스탠다드, 딥 스택으로 구분합니다.
- 폴드·체크·콜·여러 베팅 크기·여러 레이즈 크기·올인의 EV를 비교합니다.
- EV가 가까운 액션은 한 가지로 단정하지 않고 GTO 혼합 빈도로 표시합니다.
- 169개 프리플랍 핸드 클래스의 레인지 맵을 현재 노드에 맞춰 표시합니다.
- 레이크와 사용자가 지정한 베팅/레이즈 크기를 EV에 반영합니다.

## EV 모델

- 콜 EV: `승률 × (현재 팟 + 콜 금액) - 콜 금액`
- 공격 EV: `균형 폴드 빈도 × 현재 팟 + 방어 빈도 × 쇼다운 EV`
- 폴드는 현재 시점부터 `0BB`로 계산합니다.
- 균형 폴드 빈도는 베팅 크기의 블러프 손익분기점과 최소방어빈도(MDF)를 기준으로 계산합니다.
- 프리플랍은 포지션·인원·스택 구간별 기준 범위와 핸드 백분위를 이용합니다.
- 포스트플랍은 EV가 비슷한 액션에 소프트맥스 혼합 빈도를 배정합니다.

## 해석상의 한계

이 도구는 실전 의사결정을 돕는 GTO 기반 근사 계산기이며, PioSOLVER/GTO+ 같은 완전한 CFR 솔버는 아닙니다. 완전한 내시균형을 구하려면 각 플레이어의 시작 범위, 모든 허용 베팅 크기, 레이크 구조와 전체 게임 트리를 지정한 뒤 CFR 반복 계산을 수렴시켜야 합니다. 토너먼트 모드는 현재 Chip EV 기준이며 ICM, 바운티와 앤티 구조는 포함하지 않습니다.
- 필요 승률은 `콜 금액 ÷ (현재 팟 + 콜 금액)`입니다.
- 포지션 범위는 6-Max, 100BB 캐시게임의 단순화된 기준입니다.

상대의 실제 범위는 추정치이므로 교육·연습 및 핸드 리뷰용으로 사용하세요.
